## 核心操作

- [ ] **进入与状态**：打开聊天、展开工具菜单，确认本地工具开关、联网工具和权限级别可辨；长文件名、菜单和按钮在窄屏无水平溢出。
- [ ] **选择单文件**：使用系统文件选择器选取 UTF-8 CSV，显示文件名、大小和本地分析状态。取消选择或选错文件后草稿仍在，移除文件后任务不能读取该文件。
- [ ] **CSV 正常路径**：以固定样例按月汇总，确认唯一映射自动继续、歧义映射等待选择。预览的行数、总额与下载后的文件一致，原文件未变。
- [ ] **CSV 错误路径**：检查无效记录、重复表头及超过 5 MiB、50,000 条数据记录或 100 列的输入。无效记录等待用户决定；超限不生成不完整结果。
- [ ] **下载结果**：用户点击下载后，在设备文件应用或浏览器下载列表打开结果，记录实际保存位置和编码。重新打开已保存任务可查看预览。
- [ ] **目录能力检测**：能选择目录时记录只读与读写权限流程；不可用时确认界面解释原因并提供单文件与下载流程。取消系统选择器不造成授权或修改。
- [ ] **目录修改与删除**：仅在设备支持时，用测试文件检查创建、修改、删除、拒绝、浏览器权限被拒绝和完全访问模式。确认显示目标和真实结果。外部改动后检查冲突提示，记录检查与提交之间无法消除的竞争窗口。
- [ ] **权限和数据披露**：询问模式下拒绝操作不产生对应请求或文件写入；完全访问需要用户主动选择。查看并撤销授权后，后续操作不继续。模型服务商、文件范围和将发送的数据在请求前清楚。
- [ ] **联网**：使用支持 CORS 的模拟来源验证询问和完全访问。检查离线、无法读取、取消及超时提示，确认没有伪造来源。
- [ ] **暂停和恢复**：执行中切换 App、关闭标签页、系统回收或关闭 PWA，再重新打开。确认仅展示已保存的状态，用户选择继续后才恢复；结果不明的外部写入显示「需核对」，不会自动重放。
- [ ] **更新与存储失败**：运行中检查更新、储存空间不足或 IndexedDB 写入失败。确认保存状态与任务状态分开显示，失败不会宣称完成或自动发送重复请求。
- [ ] **键盘与安全区**：弹出软键盘、旋转屏幕、展开 Composer 和任务卡，检查输入框、停止按钮、审批按钮、底部安全区和滚动可达。使用外接键盘和系统屏幕阅读器检查焦点及状态播报。
- [ ] **预览文案**：逐项查看创建、修改、覆盖、删除及失败提示。确认目标路径完整可查看，关闭预览不会批准，拒绝不会写入；大文本和二进制预览清楚说明显示范围。
- [ ] **主题与语言**：分别检查 Light、Dark、System，及英文、简体中文、马来语；长文本换行后按钮和状态仍可见。记录系统字体放大后的可读性与操作结果。
- [ ] **授权边界**：撤销浏览器权限、收紧应用权限或切换模型服务商后，验证后续操作重新检查授权；目录句柄不随备份导入自动授予访问。
- [ ] **隐私与导出**：任务使用模拟敏感文本；确认诊断导出不包含文件内容、完整路径、URL 查询或密钥。确认聊天备份的实际内容与应用说明一致。
