# Browser-first 文件访问设计

**状态**：设计方案。用户可选择单个文件或授权目录。文件工具与现有 CSV 分析共同使用权限策略，入口位于 Composer 的「＋ → 工具」。 [Agent 架构](BROWSER-FIRST-AGENT.md) · [CSV 规格](COMPOSER-CSV.md)

## 文件范围与权限

| 范围 | 获取方式 | 可用操作 |
| --- | --- | --- |
| 选中的单文件 | 用户通过浏览器文件选择器选择文件 | 读取和分析。结果先预览，由用户下载为新文件。 |
| 授权目录 | 浏览器支持时，用户通过目录选择器选择目录并同意相应系统权限 | 在该目录范围内列出、读取、创建、修改和删除文件。写权限另由浏览器和操作系统决定。 |

用户只为任务授权实际选中的文件或目录，UI 显示名称、可读/可写状态及接收模型服务商。文件内容被送往模型前，按当前数据共享规则告知并获得授权。CSV 默认本地分析，原始 CSV 不因此发送给模型；月度汇总结果按用户既定的数据共享范围处理。任务完成后可在工具面板查看及撤销授权。

默认「操作前询问」下，目录内创建、修改、删除逐次展示目标路径和操作，允许用户批准或拒绝；读取授权目录时先展示访问的目标和范围并获得授权。用户主动选择「完全访问」后，已授予浏览器读写权限的目录内操作可自动进行。两种模式都受浏览器和系统权限约束。变更权限后的后续操作重新检查，已经启动的操作显示其实际结果。

## 浏览器能力与回退

- 目录访问使用支持环境中的 File System Access API，并由用户手势触发选择。读取与读写权限分别检查；权限未获授予或被撤销时暂停并说明原因。保存目录句柄后重新打开页面仍需查询实际权限，不能假设句柄自动可用。
- 不支持目录选择、缺少写权限或用户取消时，允许选择单个文件，预览结果后下载新文件。显示具体受限原因，保持聊天和草稿可用。
- 已选择的目录和文件句柄属于本设备授权，不随聊天备份、导入、跨设备或更换浏览器自动恢复。任务恢复时重新验证句柄、权限和文件版本。
- QuickJS 沙箱不直接持有句柄、网络或浏览器 API。模型通过明确的文件工具请求，由应用层检查任务范围和权限后执行。工具输出和发送给模型的数据遵循用户确认的范围。

## 操作规则

- **读取与列表**：只能使用授权目录内的相对路径，展示操作目标。限制目录遍历和返回内容大小；拒绝绝对路径、`..` 和无法验证是否位于授权范围内的目标。读取内容视作外部数据，不能改变工具权限。
- **创建与修改**：显示完整相对路径、动作、原内容摘要和拟议变化；新文件与覆盖已有文件须明确区分。提交前重新确认浏览器权限和文件版本，文件被其他程序修改时暂停并让用户重新查看。完成后显示结果。
- **删除**：显示目标和删除动作；默认询问时等待确认。删除结果按浏览器提供的实际行为呈现，不能承诺回收站或撤销。
- **恢复**：每个写操作关联调用 ID、目标和结果回执。浏览器文件系统与 IndexedDB 不能保证同一原子事务；中断或刷新后结果不明的写入显示「需核对」，由用户检查后再决定是否重试。已确认完成的动作不能自动重放。

## 创建、修改和删除交互

以下为实施建议。单个操作按一个目标文件执行，批量修改和递归删除目录需要另行设计。

### 预览结构

回复中的文件操作卡以「操作、文件名、状态」为标题，展开后按顺序显示工作区名称、相对路径、操作原因、变更内容与操作按钮。路径可换行并可展开查看完整内容，长文本区域独立滚动。卡片状态由实际操作阶段驱动。

| 操作 | 预览 | 默认询问时的按钮 |
| --- | --- | --- |
| 创建 | 路径、文件类型与大小、拟写入内容。目标存在时进入冲突状态。 | 创建文件、拒绝 |
| 修改 | 路径、变更前后的差异和文件版本。可切换查看原文与新内容。 | 保存修改、拒绝 |
| 覆盖 | 路径和现有文件信息、新内容或差异。明确标示会替换内容。 | 确认覆盖、拒绝 |
| 删除 | 路径、文件名和类型。界面说明恢复能力取决于设备。 | 删除文件、拒绝 |

以下中文文案已确认作为实施基线。文件名和路径使用界面文本节点显示，不解释为 HTML 或 Markdown；英文和马来语实现时保持相同含义。

| 状态 | 标题与说明示例 | 可用操作 |
| --- | --- | --- |
| 创建 | **创建「report.csv」**。将在「工作区 / reports」创建新文件。 | 创建文件 / 拒绝 |
| 修改 | **修改「report.csv」**。请查看以下变更，然后决定是否保存。 | 保存修改 / 拒绝 |
| 覆盖 | **覆盖「report.csv」**。该文件已存在，继续将替换其内容。 | 确认覆盖 / 拒绝 |
| 删除 | **删除「report.csv」**。文件将从授权目录中删除，是否能恢复取决于设备。 | 删除文件 / 拒绝 |
| 被拒绝 | **未执行**。你拒绝了这次操作。 | 查看详情 |
| 冲突 | **文件已更改**。请重新查看当前内容，再决定是否继续。 | 重新查看 / 取消 |
| 权限不足 | **无法访问此文件**。请检查工作区权限后重试。 | 检查权限 / 取消 |
| 失败 | **操作未完成**。显示可解释的失败原因；若结果不明则使用「需核对」。 | 查看详情 / 取消 |
| 需核对 | **请检查文件状态**。应用无法确认这次操作是否完成。 | 查看文件 / 稍后处理 |

权限确认和文件操作确认分别命名，避免把浏览器授予目录权限误解为批准某一次文件修改。「完全访问」仍展示执行状态，但不显示逐次批准按钮。动作完成文案来自实际 API 结果，用户拒绝、关闭面板或停止任务各使用对应状态。

文本差异优先采用单栏逐行展示，颜色配合「新增／删除」文字或符号；长文件分段加载并标明展示范围，不能将截断预览误作完整内容。二进制文件显示类型、大小和可用摘要，不能显示可靠差异时明确说明。批准内容与操作目标和文件版本绑定，用户更改目标或内容后需生成新的预览。

| 状态 | 行为 |
| --- | --- |
| 等待确认 | 焦点先落在拒绝或关闭上；批准只对当前操作生效。关闭预览不代表批准，保留等待状态；停止任务取消待处理请求。 |
| 执行中 | 按钮不可重复提交，显示当前动作。停止后如结果尚无法确认，显示「需核对」。 |
| 已完成 / 已拒绝 | 卡片记录实际结果。拒绝后工具返回拒绝结果，模型可说明后续选择。 |
| 权限不足 / 失败 | 显示浏览器返回的可解释原因，保留预览。需要权限时由用户触发重新授权；重试前再次检查目标。 |
| 文件冲突 | 显示目标已变化，暂停操作。重新读取并生成新预览；用户可取消或在明确确认后提交新版本。完全访问也需用户处理冲突。 |
| 需核对 | 显示目标及最后已知阶段，提供重新查看文件入口。只有用户核对后才能决定是否新建一次操作。 |

1. 模型提出文件操作后，工具卡显示工作区名称、相对路径、操作类型和状态。创建新文件、覆盖文件、修改文件、删除文件使用不同的动作名称；用户可展开查看内容变化。较大的文本变化分页展示，二进制文件显示名称、类型和大小。
2. 「操作前询问」模式下，修改预览包含旧内容与新内容的差异，删除预览显示目标文件。用户可批准一次、拒绝或停止任务。拒绝产生明确结果，模型可继续解释或请求其他操作。默认焦点落在拒绝或关闭操作上，键盘和屏幕阅读器可访问。
3. 「完全访问」模式下，无需逐次确认，工具卡仍显示操作、目标和结果。浏览器请求目录权限时仍需用户响应。该模式由用户主动选择，可随时切回询问模式或撤销工作区授权。
4. 执行前重新检查工作区授权、目标和文件版本。若目标已变化、消失或创建时名称已存在，暂停并显示冲突；询问模式下展示更新后的预览，完全访问模式也须让用户决定如何处理冲突。浏览器文件 API 没有通用的原子比较并写入能力，因此在检查与提交之间仍可能发生外部修改；界面不能承诺绝对防止覆盖。
5. 按浏览器 API 的完成结果区分「已完成」「失败」「需核对」。用户批准后，如果页面关闭或写入状态不明，恢复时显示目标及最后已知阶段，由用户查看当前文件再决定重试。文件系统写入与 IndexedDB 回执不共享事务。

工具卡中显示的文件路径和差异可能包含私人信息。它们按聊天记录的数据处理规则保存，诊断导出不包含文件内容或完整路径。没有浏览器权限、目标越界或无法可靠确认目标时，操作不能开始，界面说明原因。

## 移动端流程

1. 用户从 Composer 的「＋」选择文件。文件标签显示名称、大小和「本地分析」，CSV 按既定上限校验。用户继续在同一个输入框提问。
2. 浏览器支持目录选择时，菜单提供「选择目录」，由用户手势打开系统选择器。授权后展示目录名称和当前可读/可写状态；系统未授予写入权限时，修改与删除显示为不可用。
3. 浏览器不支持目录访问时，菜单说明该设备支持单文件操作。用户选择文件，查看结果并点击下载；不自动把下载文件写回原位置，也不把它描述为已修改原文件。
4. 中途切换 App、系统回收页面或 PWA 被关闭后，重新打开显示最后保存的任务状态。已选文件或目录不可用时，请用户重新选择并重新核验；已发送的模型请求可能已经计费。
5. 审批面板适配窄屏，路径换行并可展开，操作按钮可触摸且支持键盘和屏幕阅读器。保存权限、下载位置与系统分享菜单依设备和浏览器而异，发布前分别在 iOS 和 Android 的浏览器及安装模式上验证。

## 验收

1. 支持目录 API 的桌面浏览器可选择目录，并按两种权限级别执行列目录、读取、创建、修改和删除；路径越界被拒绝。
2. 操作前询问模式拒绝修改或删除后，文件内容保持不变。完全访问仍不能访问用户未授权的目录或绕过浏览器权限。
3. 撤销权限、目标被外部修改、写入失败、应用刷新及两个标签页竞争时，界面显示真实结果，未确认的写入不自动重复。
4. 不支持目录 API 的桌面和移动浏览器可完成选文件、本地分析、预览和下载。权限与单文件范围在发送模型请求前清楚展示。
5. 文件句柄及授权不进入备份或诊断导出；跨会话、恢复及更换服务商遵循任务数据分享规则。
6. 新建、覆盖、修改和删除显示各自的目标与结果；默认询问时批准、拒绝、取消、文件变化与写入失败均有明确反馈。完全访问模式仍展示操作进度和结果。
7. 实机验证应记录浏览器与 PWA 模式、系统版本和实际结果。执行表见 [移动端实机验证清单](MOBILE-DEVICE-CHECKLIST.md)。
