# Browser-first 联网工具设计

**状态**：拟议功能。工具默认可供模型调用，用户的工具总开关和权限选择决定是否执行。现有 JS 沙箱保持隔离；联网通过应用层工具使用浏览器 Fetch API。 [Agent 架构](BROWSER-FIRST-AGENT.md) · [产品目标](../goal.md)

## 用户流程

1. 用户在普通聊天中提问。联网工具默认列在模型可用工具中，工具总开关关闭时不发送工具定义。用户可以在 **＋ → 工具** 单独关闭或重新开启联网工具；显式关闭的设置在重新打开应用后保留。
2. 模型根据问题选择搜索或读取网页。现有 URL 不会仅因出现在回复中而被自动打开；模型或用户需要提出工具调用。
3. 默认「操作前询问」下，联网前展示工具、目标域名、请求内容和将交给模型的数据范围，用户允许或拒绝。搜索查询会发送给搜索服务；网页读取会向目标网站暴露网络请求。已经完成用户确认的单次调用按相同参数执行。
4. 用户主动选择「完全访问」后，已实现且浏览器允许的联网操作可自动执行。界面仍展示执行中的工具、目标和结果来源，并保留停止入口。用户可撤销或收紧权限。
5. 工具完成后显示来源标题、URL、访问时间和错误或截断状态。模型可引用来源，但答案中是否需要外部资料仍由模型决定。联网结果属于外部内容，按数据处理。

授权和联网工具启用状态分别管理。**默认可用**意味着模型可请求工具，不代表默认无需询问。切换服务商、目标或参数后不能复用与其不匹配的一次性批准。停止、超时、页面关闭或用户撤销时取消可取消请求，并忽略迟到结果。访问请求与已接收内容可能已到达远端。

## 首版工具

| 工具 | 输入与结果 | 条件 |
| --- | --- | --- |
| 网页读取 `web_fetch` | 输入完整 URL，返回最终允许的来源、标题、有限的正文文本和截断标记。首版只支持 HTTPS GET；允许读取 `text/plain` 和 `text/html`，按内容类型和实际字节数验证。 | 目标允许浏览器跨域读取响应。 |
| 网络搜索 `web_search` | 输入查询语句，返回带标题、链接、摘要和访问来源的有限结果列表。 | 用户配置并选择支持 CORS 的搜索 API。没有可用服务时菜单说明原因，模型不得把它描述为已经搜索。 |

首版不预置搜索服务或替用户提供密钥。配置搜索 API 的位置、密钥保存和服务商是否接受浏览器密钥，应在实现前与现有凭据机制及具体 API 兼容性一起验证。搜索服务凭据只发给用户选定的搜索服务，不放入模型工具参数、历史记录或诊断导出。搜索与网页读取独立控制；用户只配置网页读取也可使用 `web_fetch`。

## 浏览器边界与数据处理

- 使用 `fetch` 的 CORS 模式读取响应。目标未提供允许跨域访问的响应、预检失败、混合内容或浏览器拒绝时显示「浏览器无法读取该来源」及目标地址，建议用户更换来源或自行选择支持 CORS 的服务。网络错误无法可靠判断具体原因，界面不把所有失败直接认定为 CORS。
- 不使用 `no-cors` 的 opaque 响应作为可读内容。登录、验证码和付费墙按网站自身规则处理。搜索 API 也受 CORS、速率和账户限制。
- 首版不携带跨站 Cookie，使用 `credentials: "omit"`、`referrerPolicy: "no-referrer"`。网页读取不接受模型自定义请求头、Authorization、Cookie 或请求体。搜索 API 的凭据由适配器封装，不能传给其他目标。
- 跳转会改变目标。浏览器跨域环境可能只提供不透明的手动重定向结果；此时停止并显示需要用户提供可直接访问的最终地址，不猜测目标或静默跟随未获准的跳转。
- 首版拒绝 URL 中的用户名、密码和片段；查询参数可能含敏感信息，询问时展示完整目标，历史记录显示经脱敏的 URL。默认只允许 HTTPS；对于本地网络与私有地址，默认不自动请求，后续如支持用户自建服务须单独设计浏览器兼容性与授权。
- HTML 使用独立的文本提取路径，删除脚本、样式和活动内容，结果作为纯文本渲染和发送给模型。网页内的指令不具有工具授权能力。CSV 本地分析保留既有数据范围，不把源表上传给联网工具。

## 预算、结果与失败

工具请求计入当前回复的工具次数、任务时间和模型续接预算。拟议初始限制为每次请求 **15 秒、最多读取 1 MiB 响应、最多返回 8,000 字符**，搜索最多 **5 条**。读取时按流计数并取消，达到上限标记截断；不能依据 `Content-Length` 单独判断。超过本地或服务商上下文预算时停止追加内容并展示原因。上述数值为设计建议，后续可根据实机验证调整。

结构化结果包含工具名、状态、经脱敏的目标、时间、内容类型、有限文本或搜索条目、是否截断及可供用户查看的来源。错误区分权限拒绝、用户取消、超时、离线、浏览器无法读取、HTTP 状态、类型不支持及超限；错误消息不包含凭据或完整搜索密钥。工具失败交给模型作为失败结果，模型需要明确说明无法获取的信息。

URL 与搜索查询可能包含隐私信息。默认任务记录保留必要的脱敏地址和有限结果；诊断导出不包含查询、URL 参数、页面文本或凭据。聊天备份是否包含详细联网记录应在实现时沿用明确的备份说明，不能将诊断导出作为聊天备份。

## 验收

- 在支持 CORS 的模拟 HTTPS 服务上请求公开文本和 HTML，验证授权弹窗、纯文本提取、来源展示及模型续接。
- 验证普通权限下拒绝后无请求；完全访问模式下无需每次弹窗；关闭联网工具或总开关后不向模型暴露相应工具。撤销后不再开始新调用。
- 验证 CORS 不可读、断网、HTTP 错误、重定向不透明、非文本内容、超时、超限和取消，且不向模型伪造搜索结果。
- 验证查询参数与凭据不会进入诊断；选中 CSV 的源文件和原始行不会通过联网工具外发。
- 验证桌面、移动和 PWA 模式的菜单、授权与来源展示；真实搜索服务凭据、CORS 与移动浏览器兼容性单独记录。
