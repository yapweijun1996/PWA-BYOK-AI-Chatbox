# Composer 工具菜单与 CSV 分析规格

**状态**：P0 设计。工具入口参考 Open WebUI 在输入区 **＋ → Tools** 启用工具的方式。Luma 复用同一个聊天输入框、当前模型和浏览器工具运行器。 [Open WebUI 工具文档](https://docs.openwebui.com/features/extensibility/plugin/tools) · [Luma 架构](BROWSER-FIRST-AGENT.md)

## Composer 交互

| 操作 | 用户看到的行为 |
| --- | --- |
| 打开「＋」 | 菜单保留「添加附件」，并提供「工具」列表。现有工具设置和「CSV 分析」都从该列表操作。工具行显示启用、关闭或不可用原因。 |
| 自动工具调用 | Tools 沿用当前默认开启的总开关。开启时，支持原生工具调用的模型可在每轮自行选择可用工具。用户关闭后保持关闭，直到主动重新开启；`/js` 和菜单操作同一份持久设置。旧配置中已关闭的选择在升级后保留。 |
| CSV 分析偏好 | CSV 分析在本地工具总开关开启时默认可用。用户可在工具菜单为当前会话关闭或恢复 CSV 分析；显式关闭的会话偏好在切换、刷新后保留。新聊天继承总开关并默认允许 CSV 分析。关闭总开关时所有工具暂停，但保留会话单项选择。 |
| 选择分析文件 | 新添加的 CSV 默认标记为「本地分析」；从当前分支已有附件中也可选择一份 CSV。Composer 显示文件标签，说明文件留在设备，列名和汇总等获准数据会发给所选服务商。其他附件保留现有发送语义。 |
| 发送普通问题 | 模型按需选择已启用的非 CSV 本地工具。未选分析文件时不提供 CSV 分析工具，保留普通聊天及其现有工具预算。模型直接回答时不显示任务卡。 |
| 发送 CSV 分析请求 | 保持同一个发送按钮和模型选择器。已选择文件时，发送前校验文件与当前模型能力。模型首次提出有效 CSV 工具调用后，提示「正在分析」并展示任务步骤。纯文本答复将保留为普通回复。 |
| 移除文件或关闭工具 | 移除文件会撤销本轮访问。工具关闭后，已选的本地文件继续显示为不可运行，用户可重新开启或将它从草稿移除，再正常发送。原始文件不会因为关闭工具而自动成为上传附件。 |
| 工具不可用 | 已知模型不支持函数调用时，显示原因并可换模型。普通文本仍可发送；明确要求分析文件时保留草稿并说明不可运行。能力未知时允许按现有适配器发出请求，遇到明确不支持的错误后提示，保留草稿和文件。用户主动移除分析文件后可以继续普通聊天。 |

**以发送快照为准。** 工具开关与附件选择只有在用户点击发送时才写入本轮授权。等待模型选择工具时仍可使用 **停止**。运行中的模型、收件方、允许的工具和文件版本锁定在该轮；停止、暂停和恢复入口显示在当前回复的任务卡。用户更换收件方、文件或分支后重新确认授权，已保存的结果留在原分支。

**移动端和键盘。** 桌面使用锚定菜单，窄屏使用短列表或底部菜单。各工具使用有名称和选中状态的控件，支持 Tab、Enter/空格，Esc 关闭并将焦点还给「＋」。长文件名可查看完整名称，选中状态也用文字和图标表达。用同一份状态驱动普通与展开的 Composer，关闭菜单本身保留选择和草稿。

## CSV 输入

| 项目 | P0 规格 |
| --- | --- |
| 来源 | 每次分析一份用户明确选中的 `.csv`。接受浏览器报告为 CSV、纯文本或未知 MIME 的文件，并以实际解析结果确认格式。会话的隐藏分支和未选附件不进入分析范围。 |
| 编码与分隔 | UTF-8，可带 BOM；逗号分隔；接受 LF / CRLF。支持双引号字段、双引号转义及引号内的换行。遇到无效 UTF-8、分号或制表符分隔、未闭合引号，指出原因并引导用户另存为 UTF-8 CSV。XLSX、跨文件合并和自动编码识别留到后续。 |
| 结构 | 首个非空记录为表头。去除表头两侧空白后要求非空且唯一；列身份保存为索引和表头。忽略完全空白的记录，字段数不符时报告首个出错的记录号。引号内换行仍属于同一条记录。空文件和仅表头文件显示原因。 |
| 大小 | 首版上限为单文件 **5 MiB、50,000 条数据记录、100 列**。5 MiB 以原文件字节计算，表头不计入数据记录。解析时在 Worker 中检查行列限制；超过任一上限时停止分析并提示用户拆分文件，不输出不完整的汇总。 [现有附件限制](../src/attachments.ts) |
| 月度汇总字段 | 用日期列和数值列。日期接受 `YYYY-MM-DD` 或 `YYYY-MM`，按日历月份分组。数值接受带可选负号的小数，使用点作为小数点，最多 6 位小数。千位分隔符、货币符号和歧义日期先在源表规范化。 |
| 字段映射和异常 | 本地检查列名、数据类型及用户请求。日期列与数值列各有唯一匹配时自动使用，任务卡显示所选列并允许用户更改。存在多个候选、无匹配，或用户请求不明确时，暂停并请用户确认。模型推荐仅作候选，不能绕过本地校验，也不能自行改动已确认的映射。空值和无效日期/数值以错误统计和少量记录号提示，暂停并由用户选择修正文件或跳过无效记录。结构或编码错误需修正文件。有效行数为零时不生成产物。 |

浏览器 Worker 负责解析和计算。月度合计使用精确十进制算法，保留小数精度并检查范围。现有 CSV Worker 的摘要路径会限制预览行和单元格长度，适合用来查看概要，正式汇总需使用不截断的解析路径。 [现有文件 Worker](../src/local-file.worker.ts)

## CSV 输出与数据流

- **同一份汇总数据**用于消息里的表格预览、模型可见的摘要和下载。桌面与手机都能滚动查看表格；摘要显示已纳入和跳过的记录数。需要分页时显示正在查看的范围，下载仍包含完整汇总。
- **输出格式**为新 CSV，默认名 `<原名>-monthly-summary.csv`，使用 UTF-8 BOM、逗号分隔和 CRLF。首版列固定为 `month,row_count,total`，月序升序，金额保持机器可读的小数。生成后的文件和执行步骤保存在对应任务；用户点击「下载 CSV」才导出，原始文件不被写回。
- **发送给模型的数据**限于用户提示、获准的聊天上下文、列名、记录计数和有限的汇总。文件字节、原始数据行和未选附件留在设备。首次发送前展示收件服务商和数据范围；拒绝共享则不提交 CSV 分析请求。任务结果写入本地并提交回执后才显示为已保存，已缓存的 PWA 可离线查看已保存产物。
- **分享与任务预算**随本轮固定。文件分析请求的工具集合限于 CSV 读取和汇总所需的本地能力。解析、计算、预览、下载共用同一份列映射和数据范围。切换文件或收件方会使旧授权失效。

验收用例至少包括含 BOM/中文表头、带逗号及换行的引号字段、空行、列数错误、重复表头、超限、歧义日期、空数值、负数和精确小数加总。例如同月的 `0.10` 和 `0.20` 输出为 `0.30`，跳过无效记录后的总数等于各月 `row_count` 之和。用模拟服务商确认回复请求只包含经允许的数据，验证切换工具、选择不同会话、刷新恢复和手机导出。 [P0 验收清单](../task.md#browser-first-agent-tasks)

映射验收包括唯一匹配自动继续、多列候选等待用户选择、无匹配说明原因、用户更改后重新计算，以及重新选择文件时不沿用旧映射。默认本地分析与发送给服务商的数据范围在发送前可见，用户主动点击下载后才导出结果。
